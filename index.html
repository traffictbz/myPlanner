Backup & info

Blocks, sessions, and notes are stored only in this browser on this device. Private browsing, clearing site data, or device failure may erase them. Export backups regularly.

Import validates the backup and asks before replacing current data. Notes are stored locally and displayed as plain text.

Install & offline use

For reliable installation, open this site over HTTPS (for example, GitHub Pages or Netlify) and use your browser’s Install / Add to Home Screen option. Localhost is supported for development. Opening the HTML as file:// does not support service workers or reliable installation. Offline caching starts after the first visit on a supported secure origin.
